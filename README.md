A one-line patch note for a bug in real life: yawning, contagious as ever, treated as an unauthorised replication bug.

> "v4.0.2: fixed a bug where yawning in a meeting replicated itself to every attendee without consent."

## How it works

`main.py` holds the entry line as a constant, checks it against the kit's gate (UTF-8 text, 1–160 characters, not only whitespace, a single line with no control characters or padding), and writes it to `/output/entry.txt` when run with `python3 main.py`.
